Câu hỏi thường gặp

HTML có phải ngôn ngữ lập trình không?

HTML là ngôn ngữ đánh dấu dùng để xác định cấu trúc và ý nghĩa nội dung trang web.

CSS có thay thế HTML được không?

Không. HTML mô tả nội dung; CSS điều khiển cách nội dung được trình bày.

Tại sao ảnh không hiện?

Kiểm tra thuộc tính src, đường dẫn file và tên tệp; vẫn cần alt để mô tả ảnh.

Tại sao CSS không áp dụng?

Kiểm tra đường dẫn trong link, selector, cú pháp và độ ưu tiên của quy tắc CSS.

Class và id khác nhau thế nào?

Class có thể sử dụng cho nhiều phần tử; id phải duy nhất trong một trang.

Làm sao học responsive?

Bắt đầu bằng bố cục linh hoạt, Bootstrap Grid và thử trên màn hình nhỏ trước.
